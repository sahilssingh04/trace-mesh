BEYOND DIRECT RECORDS

Possible missing connections

Each suggestion comes with supporting paths. The lead score is an uncalibrated ranking, not a probability or proof.

How are these scores calculated?

Only accepted, asserted relationships contribute. Case co-mentions are excluded. Same-type people/phone pairs with shared neighbors are ranked using Adamic–Adar, Jaccard, typed intermediaries, source diversity and precise-time proximity, with penalties for conflicting claims. Existing direct records are suppressed. The calculation is a ranking rule, not a trained model.

min(90, round(100 × (1 − exp(−max(0, sum of contributions)))) )
